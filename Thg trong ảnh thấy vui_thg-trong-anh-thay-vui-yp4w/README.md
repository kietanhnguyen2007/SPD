# Team Crystallizer 🔮

This is the codebase for the **Team Crystallizer** project, submitted by team `Thg trong ảnh thấy vui` (`thg-trong-anh-thay-vui-yp4w`).

## Setup & Run

The project is built with Vanilla JavaScript (ES Modules).

```bash
# Install dependencies (only required for serving)
npm install

# Run the development server
npm run dev
```

Then navigate to the URL provided in the console (usually `http://localhost:5173`).

## Project Structure

- `src/index.html`: Main UI entry point.
- `src/css/styles.css`: Application styles.
- `src/js/app.js`: Main application logic.
- `src/js/matchingEngine.js`: Core constraint-satisfaction engine and algorithms.
- `src/js/dataStore.js`: State management and configuration data.
- `src/js/reportGenerator.js`: Report generation utilities.
- `src/data/`: JSON datasets.
- `src/tests/`: Unit tests.
